JavaScript na Prática

Pequenos exemplos, grandes possibilidades. Explore os exemplos e veja o que acontece quando você interage com a página.

Cada seção apresenta uma situação comum no desenvolvimento web. Os exemplos podem ser testados diretamente nesta página.

1. Alterando o conteúdo

O JavaScript pode modificar o texto de um elemento HTML sem recarregar a página.

<h3 id="mensagem">Olá!</h3>
<button id="btnMensagem">Clique aqui</button>

<script>
  const mensagem = document.querySelector("#mensagem");

  document.querySelector("#btnMensagem")
    .addEventListener("click", () => {
      mensagem.textContent = "Olá, JavaScript!";
    });
</script>

Olá!

2. Trabalhando com eventos

Eventos permitem responder a ações, como cliques, digitação e mudanças em campos.

const botao = document.querySelector("#btnContador");
const resultado = document.querySelector("#contador");

let cliques = 0;

botao.addEventListener("click", () => {
  cliques++;
  resultado.textContent = cliques;
});

Você clicou 0 vez(es).

3. Manipulando o DOM e o CSS

O DOM representa os elementos da página. Podemos localizar elementos e alternar classes CSS.

const caixa = document.querySelector("#caixa");

document.querySelector("#btnEstilo")
  .addEventListener("click", () => {
    caixa.classList.toggle("highlight");
  });
Esta caixa pode mudar de estilo.

4. Arrays e repetição

Arrays guardam conjuntos de valores. Métodos como forEach() ajudam a percorrer os itens.

const linguagens = ["HTML", "CSS", "JavaScript"];

linguagens.forEach((linguagem) => {
  // Cria um item para cada linguagem
  console.log(linguagem);
});

    5. Funções e cálculos

    Funções agrupam instruções que podem ser reutilizadas. Neste exemplo, calculamos a soma de dois números.

    function somar(a, b) {
  return a + b;
}

const resultado = somar(5, 3);
console.log(resultado); // 8

    Resultado: 8

    6. Consumindo dados de uma API

    Com fetch(), podemos solicitar dados de um serviço externo. Este exemplo busca usuários de uma API pública.

    async function carregarUsuarios() {
  const resposta = await fetch(
    "https://jsonplaceholder.typicode.com/users"
  );
  const usuarios = await resposta.json();

  console.log(usuarios);
}

    Este exemplo precisa de conexão com a internet.

      7. Validação de formulários

      Antes de processar os dados, o JavaScript pode verificar se os campos foram preenchidos corretamente e apresentar mensagens claras para o usuário.

      formulario.addEventListener("submit", (evento) => {
  evento.preventDefault();

  // Verifica os campos e exibe os erros.
  if (!nome.value.trim()) {
    mostrarErro("nome", "Informe seu nome.");
  }

  if (!emailValido(email.value)) {
    mostrarErro("email", "Informe um e-mail válido.");
  }

  if (senha.value.length < 8) {
    mostrarErro("senha", "Use pelo menos 8 caracteres.");
  }
});
      Importante: a validação no navegador melhora a experiência do usuário, mas não substitui a validação no servidor. Os dados também precisam ser verificados no backend.
